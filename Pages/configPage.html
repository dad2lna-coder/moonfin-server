Moonfin Settings

General

Allow Moonfin clients to sync their settings across devices via this server.

Jellyseerr Integration

Enable Jellyseerr integration for all users. Users can configure their own API keys in their client settings.
The URL of your Jellyseerr instance. If you only have one URL (e.g. a local IP), enter it here.
SSO Proxy: When Jellyseerr is enabled, Moonfin provides single sign-on. Users authenticate once with their Jellyfin credentials, and the session is stored server-side. All Moonfin clients (web, webOS, Tizen) can access Jellyseerr through /Moonfin/Jellyseerr/Api/ without re-authenticating.

RomM Server Integration

Connect to your self-hosted RomM server to stream game box art directly without storing local image copies.
The base URL of your RomM server.
Strategy for fetching box art. "RomM first" proxies art from RomM when matched, falling back to cached/libretro art.
